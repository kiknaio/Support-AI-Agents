In terms of SEO (Search Engine Optimization), while Google has the capability to crawl and index dynamic JavaScript content, many other search engine bots might not successfully manage it. Therefore, in order to prepare a SEO-friendly React.js application, developers often leverage server-side rendering (SSR) or pre-rendering techniques. 

In SSR, the content of your web application is generated directly from the server. This facilitates an easy visible access to the fully rendered page, for any bot or crawler, in a similar way a user would see it. By doing so, this eliminates the requirement for the bot to render any JavaScript, thus ensuring your content to be indexed and crawled in a correct manner.

However, using SSR is not the only technique for optimizing your React.js website for SEO. Here are a few more methods that you can put to use:

1. Semantic Markup: It is always beneficial to use the right HTML tags to describe your content in a clear manner to the search engines.
2. Meta Tags: Meta tags offer metadata about the HTML document, which browsers and search engines can utilise. For this, libraries like react-helmet within React can be highly effective.
3. Dynamic Meta Tags: If your web pages load content in a dynamic manner, dynamic meta tags can come in handy. Libraries like react-helmet can also assist with this.
4. Sitemap: A sitemap aids search engines in crawling your website and in understanding the site structure in a better way. One can also be generated with the help of multiple online tools.
5. robots.txt: This is a file that communicates to the search engine crawlers the pages or files the crawler can request from your site. Typically, you will find it located at the site root.
